## Solution

We only have a `pcap` file with recorded network traffic.
Open `capture.pcapng` in Wireshark and look at its contents.

<Image src={wiresharkPng} alt="DNS requests. Wireshark" />

There are only DNS requests and responses.

All domain names have the same format, for example `636573207175616d.attacker.com`.
Notice that `636573207175616d` looks like a hex-encoded string.
Decoding `636573207175616d` gives `ces quam`.
It is part of a longer string, so we need to reconstruct the whole thing.

Let's write a Go program that:
* reads all packets in sequence;
* extracts third-level domains (i.e. `636573207175616d`) from DNS queries and joins them into a single string;
* decodes the hex string into text.

## AES-CBC — Padding Oracle Attack

A padding oracle attack is a cryptographic attack that exploits the padding mechanism in some encryption schemes, such as CBC (Cipher Block Chaining) with symmetric encryption like AES. It allows an attacker to decrypt or modify data without knowing the encryption key.

With this attack you can:
* Decrypt an encrypted message
* Encrypt an arbitrary message

## What do you need to use a Padding Oracle Attack?

* The attacker must be able to:
  * Modify the ciphertext.
  * Send the modified ciphertext to the server.
  * Receive responses to requests repeatedly.
* The vulnerable system must:
  * Use a block cipher in AES-CBC (Cipher Block Chaining) mode or a similar mode that requires data padding.
  * Pad data with PKCS#7.
  * Indicate, explicitly or implicitly, whether the padding is correct (this can be determined from an explicit error message, different error codes, different request execution times, a service failure, or other behavior)

## How padding works and why it is needed

AES is a block cipher, so to apply AES encryption/decryption a message must be split into blocks of a certain size. In other words, the message size must be a multiple of the block size.
In general, we want to encrypt and decrypt messages of arbitrary size.

Therefore we need to be able to add and remove padding at the end of the message so that its size becomes a multiple of the block size.

The general scheme of applying padding during encryption:
```c
plaintext = get_plaintext()     // Got a message of a certain size
                                // that we want to encrypt.
plaintext = pad(plaintext)      // Added padding to the end of the message
                                // so that its size is a multiple of the block size.
ciphertext = encrypt(plaintext) // After encryption we got a ciphertext
                                // whose size is a multiple of the block size.
```

The general scheme of applying padding during decryption:
```c
ciphertext = get_ciphertext()   // Got the message that we want to decrypt.
                                // The size of ciphertext is a multiple of the block size.
plaintext = encrypt(ciphertext) // After decryption we got text
                                // whose size is a multiple of the block size
                                // (and matches the size of ciphertext)
plaintext = unpad(plaintext)    // Removed the padding from the end of the message
                                // so that its size matches the original size
                                // (before encryption was applied)
```

### How PKCS#7 works

The required number of bytes is appended to the end of the message so that its size becomes a multiple of the block size.
If the message size is already a multiple of the block size, a whole block is added.
The value of the added bytes equals the number of added bytes.

Examples
```python
"Hello World!1" -> "Hello World!12\x03\x03\x03"
"Hello World!12" -> "Hello World!123\x02\x02"
"Hello World!123" -> "Hello World!123\x01"
"Hello World!1234" -> "Hello World!1234\x10\x10\x10\x10\x10\x10\x10\x10\x10\x10\x10\x10\x10\x10\x10\x10"
"Hello World!12345" -> "Hello World!12345\x0f\x0f\x0f\x0f\x0f\x0f\x0f\x0f\x0f\x0f\x0f\x0f\x0f\x0f\x0f"
```

A possible implementation in Python:
```py
def pkcs7_pad(data: bytes, block_size: int) -> bytes:
    if block_size <= 0 or block_size > 255:
        raise ValueError("The block size must be in the range of 1 to 255")

    pad_len = block_size - (len(data) % block_size)
    padding = bytes([pad_len] * pad_len)
    return data + padding

def pkcs7_unpad(data: bytes, block_size: int) -> bytes:
    if not data or len(data) % block_size != 0:
        raise ValueError("The data has an incorrect length")

    pad_len = data[-1]
    if pad_len <= 0 or pad_len > block_size:
        raise ValueError("Incorrect padding value")

    if data[-pad_len:] != bytes([pad_len] * pad_len):
        raise ValueError("Incorrect PKCS#7 padding")

    return data[:-pad_len]
```

## Padding Oracle Attack - Decrypt

<Image src={aesCbcWebp} alt="AES - CBC" />

The attacker knows all the values of the Ciphertext blocks (IV, ct1, ct2, ..., ctN).
The attacker wants to recover all the values of the Plaintext blocks (pt1, pt2, ..., ptN).

Let's consider the decryption algorithm using the last two blocks ct1, ct2 as an example.

```py
is2 = decrypt(key, ct2) // Compute the internal state is2
pt2 = is2 xor ct1       // Compute pt2
pt2 = unpad(pt2)        // Remove the padding
```

Since the padding size does not exceed the block size, unpad affects only the last block.

In which cases can the server report incorrect padding?

Correct block formats
```txt
 _  _  _  _  _  _  _  _  _  _  _  _  _  _  _  1
 _  _  _  _  _  _  _  _  _  _  _  _  _  _  2  2
 _  _  _  _  _  _  _  _  _  _  _  _  _  3  3  3
 _  _  _  _  _  _  _  _  _  _  _  _  4  4  4  4
 _  _  _  _  _  _  _  _  _  _  _  5  5  5  5  5
.....
 _  _ 14 14 14 14 14 14 14 14 14 14 14 14 14 14
 _ 15 15 15 15 15 15 15 15 15 15 15 15 15 15 15
16 16 16 16 16 16 16 16 16 16 16 16 16 16 16 16
```

where
* `_` - any byte value.
* a digit - the byte value in decimal.

All other formats lead to incorrect padding.

### Algorithm

Notation: `ct2` is the last block, `ct1` is the penultimate block.

__Algorithm for finding the `Intermediate state` of the last block__:
* Check that the padding matches the format ` _  _  _  _  _  _  _  _  _  _  _  _  _  _  _  1`:
  * Try all values of `ct1[15]`
  * If the server replies that the padding is correct, then
    * `is2[15] = ct1[15] xor 1`
    * Move on to the next step
* Check that the padding matches the format ` _  _  _  _  _  _  _  _  _  _  _  _  _  _  2  2`:
  * Set `ct1[15]` to `2`
  * Try all values of `ct1[14]`
  * If the server replies that the padding is correct, then
    * `is2[14] = ct1[14] xor 2`
    * Move on to the next step
* Check that the padding matches the format ` _  _  _  _  _  _  _  _  _  _  _  _  _  3  3  3`:
  * Set `ct1[14]`, `ct[15]` to `3`
  * Try all values of `ct1[13]`
  * If the server replies that the padding is correct, then
    * `is2[13] = ct1[13] xor 3`
    * Move on to the next step
* Check that the padding matches the format ` _  _  _  _  _  _  _  _  _  _  _  _  4  4  4  4`:
  * Set `ct1[13], ct1[14], ct[15]` to `4`
  * Try all values of `ct1[12]`
  * If the server replies that the padding is correct, then
    * `is2[12] = ct1[12] xor 4`
    * Move on to the next step
* Using the same actions, find all values `is2[0], is2[1], ..., is2[16]`

__Algorithm for decrypting all blocks__:
* While `ciphertext` is not empty
  * Find `is2` of the last block
  * Compute `pt2 = ct1 xor is2`
  * Save the result `plaintext = pt2 + plaintext`
  * Discard the last block
* Apply `unpad` to `plaintext` to remove the padding
* `plaintext` will contain the decrypted message

The `aes_pao_dfs` function works with the last two blocks `ct1`, `ct2`.
It returns the `Intermediate state` for block `ct2`.
The `idx`, `is2` parameters are used to pass state through recursive calls.
The function tries all values at position `idx`. On success it moves to the next position.
```py
def aes_pao_dfs(ct_prefix, ct1, ct2, idx, is2, check):
    if idx == -1:
        return is2

    if idx < 0 or idx > 15:
        return None

    ct1_new = ct1[:]
    for i in range(idx+1, 16):
        ct1_new[i] = is2[i] ^ (16 - idx)

    for i in range(256):
        ct1_new[idx] = i

        if not check(ct_prefix + ct1_new + ct2):
            continue

        is2 = is2[:]
        is2[idx] = ct1_new[idx] ^ (16 - idx)

        print(f"idx={idx:03}   i={i:03}   is2={is2.hex()}   pt2={xor(ct1, is2)}", flush=True)

        res = aes_pao_dfs(ct_prefix, ct1, ct2, idx - 1, is2, check)
        if res != None:
            return res

    return None
```

Split the original encrypted message into blocks.
For each pair of blocks it returns the `Intermediate state` for the last block and removes that block.

## Padding Oracle Attack - Encrypt

Almost all of the reasoning used to find `pt` and to find `ct` is the same, because the base task is to find `is`.
And `pt` and `ct` are symmetric with respect to `is`:
```py
pt = ct xor is
ct = pt xor is
```

__Algorithm for generating all ct blocks__:
* Create a random `ciphertext` with the same size as `plaintext` (excluding `iv`)
* For each adjacent pair of ct blocks, starting from the last one
  * Find `is2` of the last block
  * Compute `ct1 = pt2 xor is2`
  * Update block ct1 in the original `ciphertext`
  * Discard the last block
* `ciphertext` contains the desired ciphertext, whose decryption yields the required `plaintext`

## Solution

### Analysis of the application source code

Let's decompile the application.
We can use any online decompiler, for example [.JAR and .Class to Java decompiler](https://javadecompilers.com).
After decompiling, we get an archive with .java files.

Three endpoints are used:
- `PUT /start/{uuid}`
  - Game initialization; `uuid` is a randomly generated value filled via `UUID.randomUUID().toString()`
- `GET /next/{uuid}`
  - Move to the next round
- `GET /accept/{uuid}/{answer}`, where `answer` is a number
  - The user chooses the correct cup

### Flag retrieval strategy

- Start a new game with `PUT /start/{uuid}`
- Repeat until we get the key:
  - Shuffle with `GET /next/{uuid}`
  - Find the ball's current position and pass it in `GET /accept/{uuid}/{answer}`
- Decrypt the flag with the key

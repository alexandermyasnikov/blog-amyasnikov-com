### Analyzing the mind-blowing.py Script

The contents of `mind-blowing.py`:

The `generate` function:
```py
def generate(seeds: list[int], idx: int) -> list[int]:
    result = []
    if idx < 0 or idx > 2:
        return result
    encoded = int.from_bytes(SENTENCES[idx], 'big')
    for bet in seeds:
        # why you're using 1s when 0s exist
        if bet.bit_count() > 40:
            continue
        result.append(encoded & bet)

    return result
```

The most interesting part of the file is the `generate` function.
The `generate` function applies the `AND` operation to each seed value and `SENTENCES[idx]`.
The restriction: a `seed` must have no more than 40 bits set to 1.

### Flag Acquisition Algorithm

We know that `A AND 1 == A`, so we use seed values in the format `0x00...00 FFFFFFFFFF 00...00`.
This lets us learn 40 bits of the `SENTENCES[idx]` string from each `seed` value.

This can be illustrated as follows:
```py
flag   = 0x <p_flag_N> ... <p_flag_2> <p_flag_1> <p_flag_0>
AND
seed   = 0x 0000000000 ... 0000000000 FFFFFFFFFF 0000000000
=
result = 0x 0000000000 ... 0000000000 <p_flag_1> 0000000000
```

After applying the `generate` function we get a list of partial values of the `SENTENCES[idx]` string.
All that remains is to apply the OR operation to obtain the original value:
```py
0x 0000000000 ... 0000000000 0000000000 <p_flag_0>
OR
0x 0000000000 ... 0000000000 <p_flag_1> 0000000000
OR
0x 0000000000 ... <p_flag_2> 0000000000 0000000000
OR
0x <p_flag_N> ... 0000000000 0000000000 0000000000
=
0x <p_flag_N> ... <p_flag_2> <p_flag_1> <p_flag_0>
```

### Writing the Solver Program

Write a program in Go.

The main part of the algorithm:

```go
	seed := big.NewInt(0xFFFFFFFFFF)
	for range seeds {
		_ = readAll(conn, "Seed of the number")
		write(conn, seed.String(), "\n")

		seed.Lsh(seed, 5*8)
	}

	result := readAll(conn, `Result: \[(.*)\]`)
	write(conn, "2", "\n")

	resultList := strings.Split(result[0], ", ")
	numResult := big.NewInt(0)
	for _, num := range resultList {
		bigNum, _ := new(big.Int).SetString(num, 10)
		numResult.Or(numResult, bigNum)
	}
```

Helper functions for interacting with the TCP server:

```go
func readAll(conn net.Conn, pattern string) []string {
	if pattern == "" {
		pattern = ".*"
	}

	err := conn.SetReadDeadline(time.Now().Add(1 * time.Second))
	checkErr(err)

	var buf bytes.Buffer
	bufTmp := make([]byte, 1024)

	defer func() {
		fmt.Printf("%s", buf.String())
	}()

	for {
		w, err := conn.Read(bufTmp)
		if err != nil {
			break
		}

		buf.Write(bufTmp[:w])

		re := regexp.MustCompile(pattern)
		res := re.FindStringSubmatch(buf.String())

		if len(res) > 0 {
			return res[1:]
		}
	}

	return nil
}

func write(conn net.Conn, msgs ...string) {
	for _, msg := range msgs {
		fmt.Printf("%s", msg)
		_, err := conn.Write([]byte(msg))
		checkErr(err)
	}
}
```

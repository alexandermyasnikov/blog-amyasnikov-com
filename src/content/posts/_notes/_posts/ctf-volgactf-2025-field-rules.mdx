## Analyzing the chall.py File

Let's look at the `chall.py` file:

<CodeFile file="chall.py" />

We can notice that `n` is a product of ~10-20 prime numbers. So we can try to factorize `n`:

```py
target_bl = len(flag) * 8
prime_base = [getPrime(m) for _ in range(-(-target_bl // m) + 1)]
n = reduce(mul, prime_base, 1)
```

```py
def encrypt(m: bytes, key: int) -> bytes:
    e = int.from_bytes(m)
    for _ in range(ROUNDS - 1):
        e += key
        e = pow(e, k, n)
    e = (e + key) % n
    return e.to_bytes(e_len, "big")

msgs, encs = [], []
for i in range(10):
    m = urandom(len(flag))
    msgs.append(m)
    encs.append(encrypt(m, key))
```

Each message is encrypted by the `encrypt` function and looks like this:

$enc_j = (...((msg_j + key)^k + key)^k + ... + key) \mod n$

Since `N` is a product of prime numbers, i.e. $N \equiv \prod_{i} p_{i}$, then

$enc_j = (...((msg_j + key)^k + key)^k + ... + key) \mod p_i$

for all factors of `N`.

We can make the transition to

$enc_j' = (...((msg_j' + key')^k + key')^k + ... + key') \mod p_i$

where

$enc_j' \equiv enc_j \mod p_i$

$msg_j' \equiv msg_j \mod p_i$

$key_j' \equiv key_j \mod p_i$

$enc_j'$, $msg_j'$, $p_i'$ are easy to compute.

We need to find the residues modulo $key_j$. They will have to be found by brute force. But since $p_i$ are not that large, it won't take much time.

After finding all $key_j$, we get a system of equations:

\(
\begin{cases}
x \equiv key_0' \mod p_0 \\
x \equiv key_1' \mod p_1 \\
x \equiv key_2' \mod p_2 \\
x \equiv key_3' \mod p_3 \\
... \\
x \equiv key_r' \mod p_r \\
\end{cases}
\)

where `x` is the flag, which is also `key`.

The Chinese remainder theorem is used to solve such systems.

It remains only to implement all the algorithms and get the flag.

### Chinese Remainder Theorem

An implementation based on the algorithm that is mentioned most often and is the simplest:

* Compute the common modulus $N=\prod_{i} p_{i}$
* Compute the auxiliary moduli $N_i=\frac{N}{p_i}$
* Compute the inverse elements $N_i^{-1} \equiv \frac{1}{N_i} {\bmod {p_i}}$
* Compute the desired value $x = \sum_{i}r_{i}N_{i}N_{i}^{-1} \mod N$

## Solution

### Input Analysis

Let's look at what `server.py` contains:

<CodeFile file="server.py" />

The server computes a `signature` for a beatmap that does not contain the marker (dorchadas). To get the flag, we need to submit a beatmap that contains the marker along with a valid `signature`.

The `signature` is computed with the md5 algorithm from the string `secret_slider + beatmap`:

```python
def sign(beatmap):
    hsh = md5(secret_slider + beatmap)
    return hsh.hexdigest()
```

### Analysis of the md5 Algorithm

Let's look at how the md5 algorithm is implemented in the Go standard library `crypto/md5`:

<CodeFile file="md5.go" />

The `Write` method processes the input string in blocks of 64 bytes. There is an internal state (four 32-bit numbers — `dig.s[0]`, `dig.s[1]`, `dig.s[2]`, `dig.s[3]`), which changes after each block is processed.

The hash is built from these same numbers:

```go
func (d *digest) checkSum() [Size]byte {
    ...
    var digest [Size]byte
    binary.LittleEndian.PutUint32(digest[0:], d.s[0])
    binary.LittleEndian.PutUint32(digest[4:], d.s[1])
    binary.LittleEndian.PutUint32(digest[8:], d.s[2])
    binary.LittleEndian.PutUint32(digest[12:], d.s[3])
    return digest
}
```

At the end, a buffer is added that contains the size of the original string and a filler of zeros up to the 64-byte block boundary:

```go
func (d *digest) checkSum() [Size]byte {
    ...
    tmp := [1 + 63 + 8]byte{0x80}
    pad := (55 - d.len) % 64                             // calculate number of padding bytes
    binary.LittleEndian.PutUint64(tmp[1+pad:], d.len<<3) // append length in bits
    d.Write(tmp[:1+pad+8])
    ...
}
```

Don't forget the alignment to 64 bytes.

So, knowing the length of `secret_slider`, we can say exactly what padding will be computed.

Plan:
* Choose an arbitrary `beatmap0` that does not contain `dorchadas_slider`, so that the length of `secret_slider+beatmap0` is a multiple of 64
* Send `beatmap0` to the server and receive `signature0`
* Choose a new `beatmap1` as `beatmap0 + padding0 + dorchadas_slider + padding1`
    * `padding0` is the padding that would be computed for `secret_slider+beatmap`
    * `padding1` is arbitrary padding to make the total string length a multiple of 64
* Create a new `md5.hash` structure with the internal state `dig.s[0]`, `dig.s[1]`, `dig.s[2]`, `dig.s[3]` from `signature0`
* Append `dorchadas_slider + padding1` and get the md5 hash, which will be the sought `signature1`

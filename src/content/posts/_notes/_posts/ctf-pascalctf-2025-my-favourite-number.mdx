### Analysing my-favourite-number.py

The `sendToAlice` function:

```py
alice_p, alice_q = getPrime(1024), getPrime(1024)
alice_n = alice_p * alice_q

print(f"hi, i'm Alice, my public parameters are:\nn={alice_n}\ne={e}")

def sendToAlice(msg):
    pt = bytes_to_long(msg.encode())
    assert pt < alice_n
    ct = pow(pt, e, alice_n)
    print(f"bob: {ct}")
```

The numbers `alice_p` and `alice_q` are private.
The numbers `alice_n` and `alice_e` are public.
Using `sendToAlice`, Bob can encrypt a message for Alice, knowing the public parameters `alice_n` and `alice_e`.
Only Alice can decrypt this message. Bob cannot decrypt it because he does not know `alice_p` and `alice_q`.

The same reasoning applies to `sendToBob`.

```py
alice_favourite_number = bytes_to_long(FLAG.encode())

upperbound = 2**501
lowerbound = 0
while upperbound - lowerbound > 1:
    mid = (upperbound + lowerbound) // 2
    sendToAlice(f"Is your number greater than {mid}?")
    if alice_favourite_number > mid:
        sendToBob(f"Yes!, my number is greater than {mid}")
        lowerbound = mid
    else:
        sendToBob(f"No!, my number is lower or equal to {mid}")
        upperbound = mid

sendToAlice(f"so your number is {upperbound}?")
```

Alice has thought of a number `alice_favourite_number` that Bob has to guess.
Bob sends his guesses using binary search, and Alice answers "greater" or "lower".

We only have the encrypted messages exchanged by Alice and Bob in `output.txt`.

The goal is to decrypt the messages and learn `alice_favourite_number`.

### Getting the flag

We cannot decrypt the messages without knowing `p` and `q`. But we can encrypt messages, knowing `N` and `e`.
We have a list of all encrypted messages, and we know the order and format of the messages from `my-favourite-number.py`.

The initial values of `upperbound` and `lowerbound` are known.
While `upperbound - lowerbound > 1`:
* read the next encrypted message from `output.txt`;
* encrypt the message `Yes!, my number is greater than {mid}`;
* if they match, change `lowerbound`;
* encrypt the message `No!, my number is lower or equal to {mid}`;
* if they match, change `upperbound`.

When the loop finishes, `upperbound` holds the desired value.

### Flag Acquisition Strategy

To get the flag, you need to buy freedom for 1337 points. Points are awarded for registering with a referral code, 100 points per user. A referral code can be created and used only once.

Create one user without a code. Create a referral code. Then create many users with this code in parallel, hoping the server won't reset the code in time.
